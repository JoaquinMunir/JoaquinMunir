### How I design

- **Layers with clear jobs.** UI, business rules and data access live apart, so each can change without breaking the others.
- **One source of truth.** A business rule is defined once and reused by the UI and the API.
- **Contracts at every boundary.** Input, and AI output too, is validated before it is trusted.
- **Phased delivery.** Small pull requests, explicit scope, and refactors that keep behavior stable.
